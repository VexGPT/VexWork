## Why this companion exists

This file preserves the **cross-Project relationship progress** that is expensive to reconstruct from a long chat, many PRs, or individually correct WorkState cards.

The concrete failure it addresses is now observed in multiple lanes:

```text
individual source / WorkState remains available
+ many Projects move independently
+ predecessor proof may remain valid while forward ownership changes
+ a fresh instance cannot safely infer all relationships from issue age / PR chronology
-> broad rereading grows
-> context windows fill
-> completed work is at risk of replay
-> stale branch evidence can be mistaken for current-main truth
```

This is a bounded continuity projection, **not** another lifecycle/status database.

Canonical ownership remains:

```text

  -> lifecycle + dependency + containment truth

target repositories
  -> product/source/runtime/proof truth

this companion
  -> cross-Project causal understanding + audit resume coordinate
```

If this file conflicts with current Workgraph or current source, the canonical owner wins.

Update this document only when the **durable relationship meaning or resume route changes materially**. Do not append routine investigation chatter.
