## Patient-zero pressure: provider work unit versus locale facets

The first localization lens correctly emitted one required predicate per target locale. Live use exposed a separate concern:

Vextreme's localization scheduler works on:

```text
one page
x one language tier
x all target locales in that tier
```

not one page/locale pair at a time.

Promoting `closed-circuit` through only the Arabic reason facet would therefore produce the wrong Work shape.

The smallest local correction is one additional required predicate:

```text
predicate.vextreme.vexsite.localization.target-tier-complete
```

It is:

```text
SATISFIED
  when every selected target locale is complete

UNSATISFIED
  when one or more selected target locales is incomplete

NOT_APPLICABLE
  when the page is source-only
```

Per-locale predicates remain exact diagnostic reason facets.

This gives VexWork one exact promotable concern that matches the provider's real work unit without widening the generic promotion foundation.
