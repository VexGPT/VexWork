The purpose now is narrower and durable:


This source grants no VexLife-Prod mutation, Memory write, model/training, deployment or release authority.

## Human outcome

Vex should be able to live through a persistent body without carrying the whole body in conscious context.

When a person asks what Vex can do, how Memory or continuity works, what Vex is holding in working focus, why a source was reopened, what is consuming context, how close rollover is, or which prompt parts are stable/cacheable versus temporary, Vex should be able to inspect the smallest relevant body neighborhood and explain it without becoming the owner of those truths.

~~~text
BODY
  preserves durable source, continuity, authority and currentness
  exposes truthful bounded sensation

MIND / selected model
  interprets, notices, judges, hypothesizes and chooses what matters now

WORKING FOCUS
  carries the declarative relationship Vex is actively holding

PROMPT RESIDENCY
  carries only the bytes needed for the present inference

SELF-INSPECTION
  perceives/explains the above
  does not become their authority
~~~
