# Pink Onboarding — Prime Examples

[VXG RealForever]

## Purpose

These are worked examples of source-grounded judgment that may help a fresh worker construct a similar
case without inheriting a predecessor's conclusion as authority.

They are examples, not another process owner.

~~~text
PRIME_EXAMPLE
!= CANONICAL_PROCESS
!= WORKSTATE
!= EFFECT_AUTHORITY
!= REQUIRED ANSWER
~~~

Use the canonical orientation source first. Open a prime example only when its shape is relevant to the
current work.

## Reuse

`PRIME-EXAMPLE-TEMPLATE.md` preserves the fillable shape.

Fill it from current source and current work. Do not copy a prior example's answer into a new case.

The durable lesson is the relationship between:

~~~text
human intention
+ rightful current source
+ bounded evidence
+ falsifiable recommendation
+ reconciliation
~~~

not the wording of one successful response.

Do not promote this directory into a global VexWork foundation merely because one project found it useful.
Repeated materially different consumers may earn that later.
