## Screen Lens completion model

The final scalable Screen Lens is one read-only application over six orthogonal coordinates:

```text
Project
× Revision
× Screen
× Expression
× Presentation
× Face
```

Meaning:

- **Project** — which Product/subject;
- **Revision** — Stable / Main / exact admitted revision;
- **Screen** — which human surface;
- **Expression** — one source-derived Product state/presentation combination;
- **Presentation** — Product-authored presentation mode such as System / Light / Dark;
- **Face** — Surface / Structure or Behavior / Depth over the same stable identities.

Changing one axis must not silently discard the others.

