# Experience Graph convergence R1

`[VXG RealForever]`

This is the small convergence experiment between the two independent VexLife-Prod E2E graph strategies.

- Claude's `src/core/experience-graph*.mjs` remains the **mechanical source reader**: Family law, Product wiring, Screen Lens/key identity, localization, route/debt derivation, law probes, perturbations and branch dynamics.
- ChatGPT's `relationship-lattice.seed.json` + `relationship-graph.mjs` remain the **human-semantic layer**: named lived outcomes, cross-owner relationships, loops, explicit projectability debt, and VexBoard/BoardJourney-oriented patient-zero routes.
- `src/core/experience-graph-human.mjs` does **not** inject the hand seed into the mechanical graph. It compares them and keeps two answers separate:
  - `structuralStatus`: can rightful source relationships form the route?
  - `experienceStatus`: can this lane actually execute and prove the human route end to end without inventing a seam?

That distinction is the main convergence. A structurally complete Vision or Voice route may still be `FRONTIER_DEBT` as a human E2E claim when the deterministic/browser/runtime harness is missing.

## What a person is actually checking

Open/run VexLife-Prod as you normally would and pay attention to these relationships, not to graph internals:

1. **Voice:** starting/stopping voice input still behaves as one Composer path, not a second conversation. The graph should know the source route; the convergence should still say when browser/runtime proof is missing.
2. **Language:** Vex reply language and VexLife screen language can move independently and remain owned by the Language Family rather than by UI widgets.
3. **Vision:** the visible control follows current Vision State. A source-complete route is not automatically called E2E-proven.
4. **Context Profile:** the accepted Send freezes the selected profile (including its optional lower input-token budget); later edits belong to the next Send.
5. **Source Return:** seeing/knowing the Source Return protocol is not the same as Product performing a lookup. Only an executed returned/no-match/held result is host-action truth.
6. **ContextShare:** include/invalidate/re-earn behavior stays a human journey/frontier until a complete typed semantic route plus deterministic browser action exists.
7. **Memory Review:** Keep may cross into semantic acceptance and Score continuity without Memory Review becoming those owners.

The separate Screen Lens lane can improve how these facts are projected. This lane decides whether the facts and their proof boundaries are coherent before projection.
