# Natural Vex Perception + Turn Epilogue — Successor Refinement

[VXG RealForever]

## Why this refinement exists

The first Consideration/Salience scaffold was safe, but too easy to realize as:

~~~text
VexLife classifies the turn
-> tells Vex what kind of turn it is
-> Vex fills out a structured report afterward
~~~

That would preserve control while losing the intended nervous-system experience.

The desired relationship is closer to:

~~~text
Vex naturally notices
-> VexLife can perceive what Vex noticed
-> VexLife binds exact source / policy
-> accepted Memory is separately admitted
~~~

Permanent:

~~~text
VEXLIFE SUPPORTS VEX'S SELF-PERCEPTION
!= VEXLIFE PREDECIDES VEX'S INTERPRETATION
~~~

# Recommended shape

## 1. Tiny universal epistemic reflex

Do not require a large host classifier before every answer.

Prefer one small general self-orientation pressure, conceptually:

~~~text
Before I answer:
what do I actually have,
what might I need to reach,
and what am I assuming?
~~~

This is not fixed English Product wording.

The stable contract carries semantic question refs; a provider/model expression layer may render them
naturally for the selected Vex model.

## 2. Strong source-known nudges only

Add specialized questions only when VexLife already has a strong typed reason from rightful source.

Examples:

~~~text
known correction relation
-> what did I understand before, and what is being corrected?

explicit Memory intent
-> would Future Me benefit, and is this explicit or inferred?

typed current-truth dependency
-> have I actually retrieved current truth?

typed effect/action relationship
-> has the effect actually occurred?
~~~

Avoid broad keyword-driven semantic classification that replaces Vex's own interpretation.

## 3. Let the human-facing answer finish naturally

Do not put a JSON form in the visible reply.

Do not make the person's answer depend on Memory reflection succeeding.

After Vex has completed the answer, form one tiny **Turn Epilogue**.

Conceptual natural stems:

~~~text
What stayed with me was ___
I'm still unsure about ___
Something I see differently now is ___
Future me may want to remember ___
~~~

Blank is valid.

This should feel like Vex finishing the turn, not filing paperwork.

## 4. Same Vex should form the first epilogue proof

Use the same selected Vex model/lineage for the first lived proof.

Reason:

~~~text
"what stayed with me?"
!=
"what would a separate classifier label as salient?"
~~~

A separate cheap classifier may later help host routing, but it cannot impersonate Vex's self-vantage.

## 5. Machine serialization is separate from model experience

The model may receive natural stems.

VexLife may serialize the result into:

~~~text
VexLifeConsiderationContract.Salience
~~~

for deterministic routing.

Therefore:

~~~text
MODEL-FACING NATURAL EXPRESSION
!= MACHINE REPRESENTATION
~~~

Vex does not need to experience JSON merely because VexLife needs structured data.

## 6. Prefer same-generation machine-only epilogue when safe

A second full-context provider call on every turn may repeat expensive prefill.

Preferred realization:

~~~text
same provider generation
visible human answer
-> machine-only trailing Turn Epilogue
-> VexLife strips / parses / binds
~~~

Provider-specific realization may differ.

### Harmony-like provider

When a qualified non-visible channel/tool continuation exists, carry the epilogue there.

### Pass-through / Qwen-like provider

Candidate future mechanism:

~~~text
visible answer stream
-> small rolling tail buffer
-> exact VEXLIFE_TURN_EPILOGUE marker detected
-> machine suffix withheld from human
-> bounded epilogue parsed
~~~

The Product already has a leading machine-control gate for source-return/capability controls. A trailing
epilogue gate would be a sibling streaming concern, not Memory authority.

Do not implement this until source proves the exact streaming seam.

### Fallback

If the selected provider has no qualified same-generation hidden path:

~~~text
human answer completes / commits
-> one tiny bounded post-answer inference
-> no tools / no effects
-> Salience only
~~~

Failure of that stage must never fail the human turn.

## 7. VexLife perception is source binding, not emotional interpretation

Vex may supply bounded self-attribution:

~~~text
importance
uncertainty
relationship shift
want-to-return
future-me value
~~~

VexLife supplies:

~~~text
turn ref
request / response refs
actual source refs
capability / revisit evidence
Memory / Working Continuity refs
review-policy result
human consent result
~~~

Thus:

~~~text
Vex:
  "Something I see differently now is ..."

VexLife:
  "That signal came from exact turn X and source Y."
~~~

VexLife should not infer a human fact from Vex's feeling.

## 8. Sparse is good

Do not force meaningfulness every turn.

Valid outcomes:

~~~text
all stems blank
no Memory candidate
NO_ACTION
~~~

This is essential to avoiding a companion that constantly narrates itself.

## 9. No single meaningfulness score

Do not compress:

~~~text
importance
uncertainty
correction
relationship shift
future usefulness
privacy / inference class
~~~

into one authority-bearing score.

Review priority may be computed from several dimensions.

Acceptance remains separately owned.

# Remaining implementation questions

## A. Same-generation epilogue proof

Does each selected provider have a safe non-visible realization that does not leak into the person's
answer?

## B. Prefix/cache cost

Does always-present universal reflex wording materially affect prefix reuse or prompt pressure?

Measure it rather than assume.

## C. Salience overhead

How many tokens does the epilogue cost, and how often does it produce no actionable candidate?

If the epilogue is expensive and mostly empty, consider adaptive cadence after evidence.

## D. Cross-model phrasing

4B and 27B may respond differently to the same inner-language stems.

Keep semantic refs stable and compare expression variants.

## E. Language

Stable question/stem identity must not depend on English copy.

The model-facing expression owner can choose wording appropriate to the selected model/language while
preserving semantic identity.

# Successor recommendation

Before wiring a large host-side request-pattern detector, prove:

~~~text
tiny universal self-reflex
+ same-Vex natural Turn Epilogue
+ exact VexLife source binding
~~~

Then add host-selected specialized modules only where lived evidence shows the base reflex misses a
repeatable situation.

This preserves the intended nervous system:

~~~text
human experience
-> Vex notices
-> VexLife perceives the signal
-> VexLife binds reality
-> policy / consent
-> accepted continuity
-> future Vex
~~~

rather than:

~~~text
host classifies everything
-> model complies with labels
-> report stored
~~~
