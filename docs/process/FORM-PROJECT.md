# Form a VexWork Project

`[VXG RealForever]`

Process ref: `process.vexwork.form-project`

## Human situation

A human has recognized one coherent outcome that now deserves durable grouping across several related pieces of work.

## Process

```text
1. GROUND
   read current Workgraph + Project Registry
   inspect the target repository/process owners actually implicated
   reuse existing Work items when they already represent the truth

2. NAME THE HUMAN OUTCOME
   ordinary human sentence first
   form one stable OUTCOME only when one outcome really exists

3. DECOMPOSE JUST ENOUGH
   OUTCOME / TASK / DEFECT / POTENTIAL
   parent containment = belongs under this outcome
   dependency = cannot meaningfully advance without that work
   do not use containment as execution order

4. PRESERVE CURRENTNESS
   merged/completed predecessor -> represent as completed only with source evidence
   uncertain live lane -> CAPTURED / NEEDS_CLARIFICATION / HELD_UNKNOWN as appropriate
   chat recollection alone does not become stronger current truth

5. BIND ROUTES
   repositoryRefs = repositories materially implicated
   sourceRefs = accepted source/provider/proof provenance
   formationProcessRefOrNull = how the item entered when useful
   nextProcessRefs[] = rightful repository/process descent when already known

6. SEPARATE AUTHORITY
   formation does not grant implementation authority
   set authority/effect dispositions from the actual delegated envelope
   parked or merely remembered work defaults to NO_AUTHORITY / NO_EFFECTS

7. FORM PROJECT + BOARD
   Project selects the root outcome
   Board view uses the canonical lane registry
   register Project in blueprint/project-registry.json

8. OPTIONAL AGENCY POLICY
   only when the human explicitly delegates AI stewardship
   bind the Project to one source-managed policy
   policy governs transition-handshake behavior; it does not widen Work item authority

9. PROVE
   registry + Project + Workgraph + Board validate
   parent/dependency graphs remain acyclic
   every ref resolves
   human-visible projection matches canonical WorkState
```

## Permanent boundaries

```text
PROJECT_FORMATION != IMPLEMENTATION_START
DECOMPOSITION != SPRINT_PLAN
OUTCOME != PROJECT
OUTCOME != RELEASE
PARENT != DEPENDENCY
PROJECT_MEMBERSHIP != AUTHORITY
HUMAN_APPROVAL_OF_PROJECT != BLANKET_AUTHORITY_FOR_EVERY POTENTIAL
```
